# Lista do Mercado

Lista de compras do mercado em PWA: itens por categoria, quantidade com − e +, caixa para marcar o que já foi pego, filtros (Todos / Faltam / Já peguei), adicionar e remover itens (com desfazer).

- Instalável no celular (Android: botão "Instalar"; iPhone: Compartilhar → Adicionar à Tela de Início)
- Funciona offline (service worker)
- Os dados ficam salvos no próprio aparelho

Site estático, sem build: basta publicar a pasta na Vercel.
